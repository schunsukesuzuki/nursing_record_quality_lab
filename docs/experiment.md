# R&D 評価計画（研究パート）

## 仮説

小型LLMは文脈に依存する表現を抽出できる可能性がある一方、誤った補完や否定表現の取り違えがある。ルールベースとの比較が必要。

## 計画

1. 合成看護記録20〜30件を生成。すべて架空。観察項目・否定・時間変化・未言及・矛盾を含む。
2. 事前に正解JSONを定義し凍結（ブラインド評価）。プロンプトやルールの設計に使用しないholdoutも分ける。
3. 比較: A=ルール、B=Qwen3-0.6B（固定モデル・設定）、必要ならC=別モデル。
4. 指標: フィールド別macro F1、否定表現正答率、`unknown`判定正答率、根拠の完全一致率、schema適合率、p50/p95レイテンシ。
5. 患者状態の観察有無・記録有無の混同が起きないかを失敗例として分析。

評価データが極小のため、統計的不確実性・一般化性能の限界を併記。サンプルの `scripts/evaluate_baseline.py` はスモークテストであり評価研究ではない。

## 数理的発展

観察・記録欠測を無視すると、施設差や患者状態の影響を誤推定する可能性がある。例えば `P(M=1 | X,H,T)` の依存構造（M=記録あり、X=患者状態、H=施設、T=時間）を検討する。ただし実データと研究倫理上の許可が必要。
